# M02 页面体验

M02 已完成，技术验证与用户页面测试均通过。以下步骤作为本片体验和后续回归依据保留，仅覆盖新增上传、来源文件和复制，不重复 M01 全套流程。

应用若仍运行旧包，先等待已保存，在原 WSL 终端 Ctrl+C 停止，再启动已构建的新包（口令不用重设）：

```bash
python3 /root/java/ResumeAI/scripts/skeleton.py run
```

打开 `http://127.0.0.1:8081/`，operator 使用原来为新工程设置的口令。

1. 同一人物下新建工作区，上传一份合成 TXT、DOCX 或文本层 PDF。当前限制 256 KiB、PDF 40 页内；扫描件不会 OCR。
2. 查看中间提取文字和遗漏说明，修正一处内容，点击“建立工作区简历”。建立前可返回，离开需明确放弃，刷新不恢复导入草稿。
3. 展开“来源信息”，点击“打开/下载导入文件”；文件应为上传原件。改简历后再次下载，原件不随正文变化。该文件不进入个人材料。
4. 再建一个工作区，点击“复制其他工作区简历”，选择刚才的来源，核对只读预览和目标后确认复制。
5. 修改副本并保存，返回来源区，确认来源未被修改。没有可选来源时应有说明，可改用导入。

正常可读文件即可，不需自行制造坏文件或并发冲突。只反馈提取/修正/复制入口是否清楚、哪里与预期不符。材料与 AI 仍未开放，不把本片确认扩大到整个 MVP。
