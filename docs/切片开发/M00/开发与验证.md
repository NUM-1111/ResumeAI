1. 保留最小前后端骨架、安全默认关闭业务路由、CSRF 和回环绑定。清理旧产物必须 Maven clean 后打包。

4. 新脚本准备数据库、校验容器标签/镜像/端口、等待就绪，凭据不进入命令行；环境不继承旧 Spring 数据源/Flyway/profile 配置。
5. 构建后执行真实数据库/HTTP 安全测试；烟测启动自己的 18081 Java，完成后停止自己的进程，浏览器检验连接和窄屏。
6. 切片过程与验证文档统一到 `/root/java/ResumeAI/docs/切片开发/`，文档检查器纳入该目录；阶段设计仍为需求依据。

## 可复现命令

Ubuntu WSL，Docker 已运行、已有锁定镜像、本地 Java/Maven 和固定 Node 缓存：

```bash
python3 /root/java/ResumeAI/scripts/skeleton.py verify
python3 /root/java/ResumeAI/scripts/skeleton.py smoke
python3 /root/java/ResumeAI/scripts/skeleton.py run
```

Windows 使用 `/root/java/ResumeAI/agentcv.ps1` 对应 verify/smoke/run。run 默认 8081，不使用旧 local.py，不需要旧用户口令。普通 verify 不自动下载新的数据库镜像或切换 Maven 镜像；缺环境则失败。当前固定 Node 路径是本机条件，不承诺跨机器开箱即用。

## 边界与技术认识

独立端口不够，必须同时分离数据空间、账号和配置入口。Flyway 幂等是重复启动不新增迁移，不是可以修改已应用 SQL；数据库标记不能冒充业务表。Maven clean 避免旧 class 和迁移残留，真实浏览器检查补足 HTTP 取到 HTML 却未执行 JS 的盲区。
