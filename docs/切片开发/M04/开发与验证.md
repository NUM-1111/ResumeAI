## 已实现第一版

V5 增加 ai_request 和公开 conversation_message；受理时检查资料范围及版本，固定简历和所选材料文本、解析限制。背景此阶段实际为 0。一次受理包含用户消息和输入快照，外部调用不占数据库长事务。

后台单执行器、全局最多四条受理/未保存结果，同区一次一条。ACCEPTED 可领取，进入 CALLING 后不自动重调；进程重新启动把遗留 CALLING 标为 UNKNOWN。未知结果须用户确认风险再主动发送。回答先存内存暂存区，再落库；失败可重试保存，不重调模型，进程丢失时不保证找回答案。

前端展示服务、范围、简历开关、材料限制，发送前保存简历，轮询原请求；旧消息暂不携带，明确提示后续 M05 才提供持续交流。普通构建及浏览器回归不继承真实密钥，避免误收费。
