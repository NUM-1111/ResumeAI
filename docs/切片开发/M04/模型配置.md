# DeepSeek 模型配置

当前推荐 deepseek-flash，固定官方端点，非流式、关闭思考。M04 仍在开发验证，先使用合成材料测试，不将接入页面当作全部保护已验收。

## 推荐：项目根目录 .env

项目启动脚本已支持读取 `/root/java/ResumeAI/.env`。首次创建（已有文件不要覆盖）：

```bash
cp -n /root/java/ResumeAI/.env.example /root/java/ResumeAI/.env
chmod 600 /root/java/ResumeAI/.env
```

在 VS Code 打开 `.env`，将自己的密钥填在 `DEEPSEEK_API_KEY=` 后面并保存，再启动：

```bash
python3 /root/java/ResumeAI/scripts/skeleton.py run
```

`.env` 已被 Git 忽略，`.env.example` 仅保存空示例。密钥以明文保存在本机 `.env`，请保持权限 600，不上传或截图。不要使用 `VITE_` 前缀，否则可能误作前端配置。更改后重启应用生效。

只读取 `DEEPSEEK_API_KEY`，不执行 shell 内容或变量替换；支持空行、整行注释和单/双引号。文件中的值不要附加行尾注释。若 shell 已设置同名变量，**shell 值优先**；希望使用文件值时先执行 `unset DEEPSEEK_API_KEY`。直接 `java -jar` 不会自动读取 `.env`，请使用上述启动脚本。

## 可选：仅当前终端环境变量

在启动应用的同一个 Ubuntu WSL 终端中，交互输入密钥，不回显，不把明文写入命令历史：

```bash
read -rsp 'DeepSeek API Key: ' DEEPSEEK_API_KEY
printf '\n'
export DEEPSEEK_API_KEY
python3 /root/java/ResumeAI/scripts/skeleton.py run
```

环境变量供后端读取，不进入前端、Git 或数据库快照。密钥不要发到聊天。Ctrl+C 退出后可执行 `unset DEEPSEEK_API_KEY` 从当前 shell 环境移除。不要用带明文密钥的 export 命令，不开启 shell 调试回显。

普通 verify/smoke 自动排除真实密钥，不产生真实模型调用。真实调用需应用在此环境启动后，选择合成资料并主动发送。实际费用以供应商账单和返回用量为准，不根据模型回答推测费用。余额不足/鉴权失败明确提示；网络超时不自动重调，避免重复收费。
