## 用户路径与边界

- 选择人物即可进入个人材料，不必先建立工作区。与导入工作区简历完全分开，不自动建立或替换简历。
- 上传 TXT/DOCX/文本层 PDF 或粘贴文字，文件默认以文件名保存，可之后重命名；同名/相同原始内容只提示，明确保留两份才新增，不覆盖合并。
- 正常解析后即可参考，不提供整份真实性认证门禁或用途分类。部分可读内容保留解析范围说明，无可读文字/彻底失败不创建可参考材料，可重新上传或粘贴。
- 添加时多选同人物工作区，默认全不选；不选只保存材料。保存后可调整去向，工作区也有管理入口。管理操作只改变允许范围，不表示模型已读取。
- 列表按导入/正文更新时间倒序，名称搜索、分页、空库与搜索无结果分别提示。查看和重命名不改变正文时间；名称允许重复。
- 文本手动保存/取消，原件不变；材料共享，后续各引用区使用新保存文本。旧版本修改冲突，保留输入，可核对最新内容；不自动改简历或背景。
- 原件下载需人物归属校验；粘贴材料无原件按钮。原件失败与文本失败分开，支持原件保存重试。材料文件纳入清理引用保护。
- 正在保存时不切走；未保存编辑/参考选择离开前提示，可复制或明确放弃。刷新/关页仅保护提示，不承诺恢复未保存编辑。登录过期在原工作台重新登录，不自动重放材料写入。

## 数据与接口契约

Flyway V4 新建 `material`、`workspace_scope`、`workspace_material_reference`，不修改已执行迁移。材料属于人物、引用使用工作区/材料/人物复合外键；材料与简历来源分开保存，多区引用同一原件。

| 接口（均在 `/api/v1/profiles/{p}` 下） | 契约 |
| --- | --- |
| GET `/materials?q=&offset=0` | 每页 25，has_more；正文更新倒序和 UUID 倒序，非全文检索 |
| POST `/materials` | name、text/base64 二选一、keep_duplicate；201，默认无引用，不触发模型 |
| GET `/materials/{m}` | 实际正文、row_version/text_version、原件与解析信息、引用工作区编号；不返回存储路径 |
| PATCH `/materials/{m}` | name 或 text 单独修改、expected_version；名称不推进正文版本，文本保存推进正文版本及时间 |
| GET `/materials/{m}/file` | 认证和归属校验，attachment/no-store/nosniff；无原件明确拒绝 |
| POST `/materials/{m}/file/retry` | 只恢复原件正式化，不重复创建材料 |
| GET `/workspaces/{w}/references` | 范围 version 和材料列表，显示允许参考而非已读取 |
| PUT/DELETE `/workspaces/{w}/references/{m}` | expected_scope_version，CSRF/幂等/归属及原子范围版本校验；冲突拒绝 |

业务写入复用 operation 幂等事务；重复上传成功请求在重新解析前先回放，避免原临时上传已结束后重试失效。材料提交、文件正式化和参考设置分别处理，参考失败不撤销材料、不要求重新上传；前端保留失败去向勾选。范围并发条件使用页面已知版本，不通过先读新版本掩盖冲突；刷新参考状态后需用户核对再保存。

初始限制复用 M02：文件和正文 256 KiB、PDF 40 页、DOCX 解压 8 MiB/256 项，解析单槽与五秒上限；不是恶意文件沙箱。重命名/正文编辑的预期版本为材料行版本。分页为 offset，修改排序字段后应重新搜索或刷新，不承诺跨请求列表快照。

复核修正：旧 M01 测试原本断言 material 表不存在，现改为断言简历建立不会给该人物新增材料，避免用旧实现结构代替业务边界。补原件重复创建请求回放，材料引用纳入文件清理保护；参考改动也参与离开保护，保存中切区阻止。

截图回读发现中间参考数量已更新但右侧仍显示旧数量，补组件范围事件同步，浏览器新增选用后 1 份/停止后 0 份断言；最终重新构建、22 项后端测试及 M03 浏览器检查通过。桌面与窄屏截图使用本机已有字体，仅测试加载、不分发字体。文档链接与 diff 空白检查通过。
