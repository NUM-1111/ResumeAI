# M05 初步页面体验

本片基础验证通过，完整收束仍在进行中，暂不标已完成。使用合成资料与问题，旧应用需保存后 Ctrl+C，再运行：

```bash
python3 /root/java/ResumeAI/scripts/skeleton.py run
```

1. 进入工作区，输入一条问题但不发送，等“草稿已保存”后刷新，应恢复输入；切换另一工作区不应带入这份草稿。
2. 可用合成问题连续问答；下一条可以引用前面的讨论，历史仅按容量携带近期完整交流。每次发送会调用真实模型并产生费用，不需反复发送测试。
3. 从 AI 顶部“⋯”选择“不携带此前聊天，继续对话”。确认后旧消息仍可回看，显示分隔线，未发送草稿保持；后续请求不再携带分隔前的聊天，简历、材料和背景范围不变。
4. 选择“清空记录并开始新对话”，先阅读确认提示；成功后消息和草稿均清空，界面不能恢复，不另存旧会话，不改简历或材料。
5. 正在回答期间可输入下一条但不能发送；不能通过菜单暗中取消请求。回答结束不应清除下一条草稿。

不需要手动制造断网、过期版本或重复调用。出现失败先保留文字，按状态提示重试保存或查询原请求，不反复发送。反馈操作、结果和预期即可。本片暂不支持背景确认和管理，后续另片交付。
