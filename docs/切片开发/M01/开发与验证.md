## 范围与实现

依据 `/root/java/ResumeAI/docs/阶段设计/05_开发计划.md` 的 M01。只实现 Session 登录、人物与工作区、粘贴预览建立工作区简历、自动保存和重开。文件上传/复制、个人材料、AI、背景和聊天未开放。

- Flyway V2 在本轮独立 `m00_app` schema 追加 profile、workspace、简历版本/当前指针与 operation，不加载旧迁移，不连接旧 55433。
- 业务后端在 `workspace` 包，HTTP 错误在 `api` 包。SQL 参数绑定，工作区行锁保护初始化和保存，版本条件控制覆盖。
- 幂等键以方法与归属路径分作用域，事务级 advisory lock 保护并发首次提交；相同请求回放结果，异载荷冲突。回放前仍校验归属。
- 登录用 BCrypt 散列、服务端 Session、CSRF 和进程内全局限流 10 次/分钟；重启限流计数重置，不代表完整攻击防护。
- 新工程口令单独保存在 `.local/m00/operator.hash`，不读取旧用户口令；设置入口交互输入，测试用临时内存口令。
- 页面显示三栏、窄屏导航/主视图切换、创建弹窗、名称搜索/分页、同名时间辨识、状态反馈、来源说明和离开保护。
- 约 800ms 停顿保存；旧响应只确认对应提交文字，冲突不覆盖；新建/保存网络失败保留操作键，内容变化生成新键。
- 登录过期在原页面重登，保存前核对版本，不自动重放。浏览器只存上次位置标识及展示名，不把简历正文作为持久草稿。

## 接口与数据约定

API 均在 `/api/v1` 下，业务资源需登录；写操作需 CSRF 与 UUID `Idempotency-Key`。

| 路径 | 输入/响应 |
| --- | --- |
| GET `/csrf` | 匿名可取 token/header_name，no-store |
| GET `/session` | 登录状态，未登录 401 |
| POST `/login`、POST `/logout`（无 API 前缀） | 表单账号/口令，成功 200 JSON / 退出 204；失败 401，限流 429 |
| GET/POST `/profiles` | 名称搜索 q、UUID after；创建 display_name |
| GET/POST `/profiles/{p}/workspaces` | 同上；创建 name/direction |
| GET `/profiles/{p}/workspaces/{w}` | 归属、方向、创建和实际简历编辑时间 |
| GET `/profiles/{p}/workspaces/{w}/resume` | initialized/version/text/source_kind |
| POST `…/resume/initialize` | text/expected_version=0，仅待建立区允许 |
| PUT `…/resume` | text/expected_version，冲突 409；相同文字仍检查版本，不新增修订 |

列表每页 25 项、最多取 26 判断下一页，以 UUID 稳定分页，同名不合并。名称最长 100、方向 200、搜索 200 字符；正文 UTF-8 256 KiB、允许换行/Tab，拒绝其他控制符。错误 `code/message/retryable/request_id` 不回传 SQL、正文或秘密。材料/背景表尚不存在，粘贴建立不产生材料条目或确认经历。

## 技术认识与边界

保存冲突不只需要按钮禁用，还要数据库原子检查；初始化不存在时锁工作区行。浏览器失去响应后不是操作必定失败，幂等回放与版本检查共同防止重复。登录恢复不能为了顺滑自动重放旧写入。测试接口语义时应比较序列化后的数值，而不是 Java 容器内部整数类。

当前没有实时协同或合并；冲突页保留输入，可查看最新文本后复制和明确放弃。全量安全、容量/运行恢复在后续切片组合验证，但本片权限/CSRF/版本/幂等/保稿不能延后。
