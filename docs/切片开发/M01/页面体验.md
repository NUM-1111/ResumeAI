本片已完成。用户已依据本指南确认页面测试没有问题；该确认仅限 M01，不扩展为整个 MVP 验收通过。仅体验已实现的粘贴建立与保存，不测试上传、复制、材料或 AI。

当前使用 Ubuntu WSL 终端（提示符类似 `root@Legancolie:~/java/ResumeAI#`），直接执行 Linux 命令。首次设置新工程口令，旧口令未自动迁入：

```bash
python3 /root/java/ResumeAI/scripts/skeleton.py set-password
python3 /root/java/ResumeAI/scripts/skeleton.py run
```

Docker 和专属数据库需运行；开发环境已准备时不必重复 verify。Docker/WSL 重启后可先执行 `python3 /root/java/ResumeAI/scripts/m00_database.py` 启动专属数据库。口令 6—32 字符且不超过 72 UTF-8 字节，不回显、不发到聊天，启动后生效。WSL 中不执行 `powershell.exe` 或 `.ps1`；仅在另行打开的 Windows PowerShell 终端中才使用该包装入口。

打开 `http://127.0.0.1:8081/`，账号 `operator`：

1. 新建“演示人物”，再新建工作区“后端版”，方向“Java 后端”。创建后直接进入，不需要再次寻找。
2. 中间粘贴下面文字，点击“预览并修正”，改一处文字，再点击“建立工作区简历”。这不会添加个人材料或确认背景。
3. 修改正文，等待“已保存”，刷新页面，确认修改仍在并返回同一工作区。
4. 导航返回上层浏览，正文应继续保留；可以再建同名工作区，名称与方向/时间辅助区分。
