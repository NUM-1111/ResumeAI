# 当前运行维护

适用当前WSL单机单实例。项目路径 `/root/java/ResumeAI/`。完整环境前置与首次口令设置见[根README](../../README.md)，用户操作见[使用指南](../使用指南.md)。

## 启动与更新

```bash
python3 /root/java/ResumeAI/scripts/skeleton.py run
```

日常使用已构建JAR，入口为 http://127.0.0.1:8081/ 。Docker须可用，脚本准备专属数据库。停止前等待“已保存”，在启动终端Ctrl+C；不要停止未知进程。

代码更新后保存工作，停止旧应用，执行verify，成功后run。重新构建不会更新运行中的JVM。

```bash
python3 /root/java/ResumeAI/scripts/skeleton.py verify
python3 /root/java/ResumeAI/scripts/skeleton.py run
```

verify使用m00_test及独立测试文件，不替代正式资料备份。浏览器回归命令为skeleton.py smoke，使用18081和测试配置，不调用付费模型。

## 配置与数据

正式容器agentcv-m00-postgres，端口55434，数据库agentcv_m00，schema m00_app；正式文件目录 `.local/m00/resume-files`。配置、数据库凭据及操作者散列位于 `.local/m00/`，模型密钥位于根.env或环境变量，不进入Git。旧55433数据库不自动迁入。

模型配置变更需重启，参考[配置步骤](../阶段/P1_MVP/切片开发/M04/模型配置.md)。当前HTTP/1.1、总响应期限默认180秒，无自动重试；JVM默认使用TieredStopAtLevel=1规避已遇C2崩溃，峰值性能可能降低。
