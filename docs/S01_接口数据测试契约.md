# S01 第一业务切片契约（实现前基线）

范围：单操作者会话/CSRF；档案及工作区创建/选择、方向；UTF-8 纯文本粘贴或 txt 上传、可编辑检查确认；三种起始稿；当前稿独立编辑、自动保存、重新打开、失败及复制兜底。不含 AI、辅助引用、文档解析、当前稿替换比较、删除恢复和历史界面。

## 接口

均基于 /api/v1；P=/profiles/{profileId}，W=P/workspaces/{workspaceId}。写操作带 CSRF 及 Idempotency-Key（UUID）；成功结果及操作记录同事务。幂等作用域=单操作者+方法+完整路径；相同键不同 JSON 载荷 409，相同请求返回原结果。页面失败保留原请求键，编辑后生成新键。列表 limit 默认 25、最大 100，after 为 UUID，id 升序且返回 nextCursor，不包含简历正文。

| 方法路径 | 请求字段 | 结果 |
| --- | --- | --- |
| GET/POST /profiles | POST displayName(1..100) | id/displayName；创建201 |
| GET/POST P/workspaces | POST name(1..100), direction(1..200) | id/profileId/name/direction/rowVersion；201 |
| PATCH W | name,direction,expectedVersion | 条件修改、版本推进；200 |
| GET/POST P/material-imports | POST name,text 或 name,base64（二选一）,keepDuplicate | id/name/checkState/rowVersion；POST 201，列表仅元数据 |
| GET P/material-imports/{id} | 无 | extractedText/confirmedText/checkState/rowVersion；原件路径不返回 |
| POST P/material-imports/{id}/confirm | text,expectedVersion | 检查确认；不能据此确认事实；确认后不可原位重写 |
| POST W/resume/initialize | sourceType=MATERIAL_REVISION/IMPORTED_REVISION/WORKSPACE_CURRENT,sourceId,expectedSourceRevision | 材料必须CONFIRMED、版本匹配，区当前稿必须同档案；独立初始v1，存在当前稿409 |
| GET W/resume | 无 | initialized=false，或 text/revision/clientEditSequence/sourceKind；无稿不以空稿冒充初始化 |
| PUT W/resume | text,expectedRevision,clientEditSequence | 版本条件保存、新修订及已确认序号；相同文本不增修订但仍校验预期版本 |

400参数/缺幂等键，401未登录，403 CSRF，404归属链不可见，409版本/重复/未确认/已初始化，413超限，422编码/类型不可处理，503持久化暂不可用。错误 code/message/requestId/nextAction，不回传正文、路径或堆栈。重复输入409 DUPLICATE，页面明确“保留两份”才以 keepDuplicate=true 重试，否则取消；本切片不实现比较更新，不提供静默覆盖。

试验限制：文本 UTF-8 字节最多256 KiB、不得为空或含NUL/非法控制字符；上传仅 .txt，严格UTF-8（允许BOM），拒绝非法字节而非替换乱码。JSON 请求体上限512 KiB，上传以 base64 放JSON，服务端再次限字节并验证。参数为本切片有限上限，不承诺其他编码；后续可配置调优。

## 数据及事务

V2 只追加迁移：profile → workspace → material_import → resume_revision → current_resume → source_binding → operation。UUID键；workspace/profile、material/profile、revision/workspace/profile 使用组合外键 RESTRICT。所有查询使用归属路径；新对象同名可共存。direction 修改推进 target_version，当前没有分析任务。

文本原件存 `/root/java/ResumeAI/.local/materials` 随机UUID文件，目录700/文件600；数据库存原件哈希、提取及确认文本；不作为公开静态资源。文件先独占写入再提交元数据；事务失败遗留孤立文件不自动删除，记录风险并留待后续维护流程，不显示导入成功。

同档案创建/修改在档案行短事务锁内序列化，包括目标区与来源；简历写入、追加不可变修订、来源出处/绑定及幂等结果原子提交；材料确认不能被保存/复制替代。复制继承当前来源材料绑定，但不引用辅助材料或复制任何JD/任务。日常编辑不清绑定；本切片不提供来源独立化。不同键并发保存相同预期版本只有一个成功。

## 页面及测试

左侧档案/工作区，中央唯一当前稿，右侧材料检查/初始化与本切片边界说明。900ms 停顿自动保存；单飞、编辑序号确认，响应期间新编辑仍为未保存。失败不无限重试，按钮显式重试；响应丢失用原幂等键，冲突不覆盖；复制页面快照不更改保存状态；剪贴板失败提供可选中文本。切换先保存，失败留页，可明确放弃未保存后离开；beforeunload 警告，不承诺关页恢复。

测试S01-01..08：登录/CSRF；双人物归属链；未确认拒绝；确认修正文持久化；保存重开及同文不增版；过期并发冲突及事务回滚；相同key重试/异payload冲突；中文txt编码/重复/超限；三种起点独立复制及绑定继承。前端确定性测试旧响应/新编辑、失败重试及冲突不误报，页面操作另记实际是否执行，不能以API测试冒充浏览器验收。AT只记录对应子集，不宣称整组通过。
