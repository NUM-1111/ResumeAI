## 保留限制

API超时根因未证实；JVM C2崩溃靠启动参数规避。精确故障组合、负载、完整安全扫描、备份恢复及完整结构化真实任务证据有缺口。进程崩溃可能丢失暂存回答，当前仅支持单机单实例。

AI不自动写回简历，模板、PDF及自动成稿未交付；完整任务成本收益尚未证明。后续事项统一见[待办与已知问题](../../待办与已知问题.md)。
