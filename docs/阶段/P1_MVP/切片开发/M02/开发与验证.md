## 交付路径

1. 新建工作区，选择上传或粘贴；TXT/DOCX/文本层 PDF 在后端提取文字，中间预览并修正后明确建立工作区简历。
2. 上传原件仅关联此工作区来源信息，可下载；简历后续编辑不改原件，不自动加入个人材料或模型上下文。
3. 选择同人物其他已有简历的工作区，按名称搜索/分页、只读预览，再确认复制；来源和目标独立，不复制其他资料。

## 数据与接口

- Flyway V3 只追加 `resume_origin` 及来源类型扩展，不修改已执行 V1/V2；M01 历史粘贴记录保持 PASTE。
- `POST /api/v1/profiles/{p}/workspaces/{w}/resume/upload-preview`：name/base64，CSRF 与幂等键。成功返回上传 ID、文本、已知限制和一小时有效期；无持久导入草稿，重启后预览 ID 失效。
- `POST …/resume/initialize`：粘贴 text 或 upload_id+修正 text，或 source_workspace_id+expected_source_version。客户端声明不能代替后端归属、来源文本和版本核对。
- 复制事务按 UUID 顺序锁来源/目标，检查来源预览版本和目标尚未初始化；变化返回 SOURCE_CHANGED/ALREADY_INITIALIZED，不覆盖。
- `GET …/resume/origin/file`：先验证人物归属，再由随机 UUID 读文件，attachment/nosniff/no-store，不根据文件名拼路径。浏览器下载后可用本机软件打开，MVP 不建在线阅读器。
- `POST …/resume/origin/retry`：只重试该区既有文件正式化和状态，不产生简历修订。

## 解析与文件一致性

初始受限参数：文件/提取文本各 256 KiB；PDF 最多 40 页；DOCX ZIP 解压最多 8 MiB/256 项。单解析槽，五秒等待上限；超时返回后实际线程结束前不释放槽，不叠加无限解析线程。不是恶意文件沙箱，不承诺强制终止和进程内存隔离。

TXT 严格 UTF-8，允许 BOM；DOCX 读取段落/表格，PDF 只读文本层。不能证明发现全部遗漏，页面展示实际可读范围的限制。扫描/无文字、损坏、不支持、加密或超限不冒充完整成功。

原件存专属 `.local/m00/resume-files`，目录 700/文件 600。临时文件先写，数据库短事务保存文本与 PENDING 来源，提交后原子移动文件并更新 READY。失败明确“文字已保存、文件未就绪”，可只重试文件。数据库状态更新失败不伪装整体成功；回放初始化先复用数据库结果，不要求重新上传或重复建稿。

清理在后续上传前触发：先查询数据库引用，查询失败则停止清理；过期临时文件一小时、无引用正式孤儿一天后清理，不删有效引用或进行中上传。不是周期运维服务，M08 再组合验证；文件正式化后进程崩溃可用文件重试补状态。未建立的预览及修正不承诺刷新恢复。
