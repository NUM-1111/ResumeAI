# M07 页面体验

本片基础实现可体验，尚未标完成。请保存编辑，Ctrl+C 停止旧应用，再启动并刷新浏览器，无需重设口令或密钥：

```bash
python3 /root/java/ResumeAI/scripts/skeleton.py run
```

1. 使用合成人物中已有的一条背景；没有时可先按 M06 创建并确认。从左侧导航点击“查看个人背景”（窄屏先打开顶部“导航”），中间显示实际已保存记录，每条下方均有“纠正”和“撤回”。用户可自行修改，无需 AI。
2. 点击“纠正”后立即打开编辑弹窗，在弹窗内输入准确内容，例如把“负责部署”改成“仅协助部署”，点击“提交纠正”。随后进入确认弹窗，显示原记录与拟修改内容，此时尚未生效。右侧 AI 栏不重复展示这次列表操作的确认提示。
3. 在弹窗内点击“确认纠正”，成功后窗口关闭、列表显示新内容；刷新背景仍保持。取消或 Escape 不执行变更。保存失败窗口保留，并在窗口内提示，可对原操作重试。对话草稿不应丢失，简历、材料及旧聊天不应被改写。
4. 点击某条“撤回”，阅读确切原文和影响，先取消一次，原记录应保留。再操作并“确认撤回”，该条从有效列表移除，背景数量更新；界面不提供直接恢复。以后要重新加入，须重新提炼并确认。
5. 可在普通对话中提出：“把个人背景中项目 A 的部署职责纠正为仅协助部署”或“撤回背景中项目 A 部署这条”。这一步会调用真实模型；目标不明确时应先澄清。得到确切变更提议后，点击“核对并确认背景变更”，在弹窗核对后确认。AI 口头说完成不等于后台生效，以实际列表为准。
6. 同人物其他区主动发送后使用最新背景。回答期间也可在列表改背景，在途回答应标明基于变更前依据，不自动重新调用；下一次主动提问采用新内容。

不需要为制造故障重复调用模型。版本冲突时保留本页输入，刷新查看最新内容后再决定；保存失败可对原提议重试确认，不必让模型重做。纠正/撤回及查看操作本身不调用模型。

可选真实冲突体验：分别说明“是另一个项目”“原记录不准确”“只讨论简历措辞”“暂时不处理”。预期分别为补范围、新纠正提议、不写入、保留分歧继续交流。发现模型没有遵守请反馈，不把一次正确回答当作所有冲突均能识别。
