# M03 页面体验

本片技术验证通过，待用户体验确认。只体验个人材料和参考设置，AI 尚未开放，不要求重复 M01/M02 全套操作。

若应用仍运行旧包，先等已保存，在原 WSL 终端 Ctrl+C，再启动已构建新包，口令不用重设：

```bash
python3 /root/java/ResumeAI/scripts/skeleton.py run
```

打开 `http://127.0.0.1:8081/`，使用 operator 及原有新工程口令。Docker/WSL 重启后先执行 `python3 /root/java/ResumeAI/scripts/m00_database.py`。

1. 选择一个人物，点“个人材料”。没有工作区也应可以进入，点“＋添加个人材料”。
2. 填“项目补充说明”，粘贴下面的合成文字。参考去向默认都不选，直接保存，材料仍应可查看。
3. 若人物下已有多个工作区，可在材料详情勾选两个去向并保存。进入其中一区管理材料，应看到“本区参考中”；取消一个区不删除文件，也不影响另一区。
4. 点击“重命名材料”修改名称；再“编辑材料文本”，修改后明确保存。取消修改应保留旧内容，不自动改工作区简历。
5. 可另上传一份小型 TXT/DOCX/文本层 PDF；查看提取内容和限制，下载原件。材料文本修改后，下载的原件仍是上传文件。
6. 搜索名称和清空搜索，确认能找到材料；查看材料后可返回工作区简历，简历仍在。上传材料不会自动建立或替换工作区简历。

```text
合成项目补充：参与订单接口开发，协助部署。
仅用于软件体验，不是真实经历。
```

材料不要求整份真实性认证，选择参考不表示 AI 已读过。只需反馈入口、共享关系和保存结果是否清楚，不需要 F12、UUID 或自行制造故障；重复请求、归属、冲突和参考保存失败由助手验证。
