## 更新与安全重启

1. 保存简历/材料和聊天草稿。若回答显示“未保存”，先重试保存或复制；进程重启可能丢失内存暂存回答。
2. Ctrl+C 停止当前应用，等命令退出再启动。不要强停未知进程或删 worker.lock 来绕过保护。
3. 启动并刷新浏览器，无需重设 key 或口令：

```bash
python3 /root/java/ResumeAI/scripts/skeleton.py run
```

数据库专属容器自动准备，Docker 服务须可用。正常启动使用 m00_app 和 `.local/m00/resume-files`；verify/smoke 使用 m00_test 和独立测试文件目录。旧 55433 数据库不动。

## 页面体验

- 在“个人背景”纠正一条合成记录，提交后在最终确认前刷新；重新进入个人背景，点击“继续处理待确认背景变更”，可以核对并确认或取消，不用清空聊天。
- 右侧AI对话栏，保存一份未发送草稿，正常退出/重启后回到原工作区，已保存文字应恢复，不自动发送。
- 已完成回答正常重开可回看。如果旧请求可能已外发但未获可靠结果，显示 UNKNOWN，只在明确确认风险后允许新调用；不会自动重调。
- 若重启前有未保存回答，重启后可能提示暂存丢失。页面若还保留回答先复制，不误解为供应商未执行。

## 当前运行边界

单实例、单执行线程，全局最多4活动请求，同区一次一条。完整 HTTP 等待60秒，连接15秒，排队时间另计。停止等待不保证供应商取消或停止收费。上限可由 Spring 配置 `agentcv.ai.max-active` 修改，当前无压测依据，不建议为求快调高。

临时文件1小时、无引用正式文件1天后符合清理条件；有效原件不清理，数据库不可读不删文件。已终结请求的残余快照超过1天可清空；公开消息和有效业务不按期限自动删除。幂等凭证目前保留，避免旧操作被重新执行，长期存储增长尚需监测。
