# P2 需求分析

状态：功能方向已认可，非实现或验收通过。承接[P1需求](../../P1_MVP/阶段设计/01_需求分析.md)，只记录本阶段增量。

## 问题与目标

用户第一阶段反馈：回答需整段等待；文字建议需要手动搬运；聊天区窄、资料范围占空间、正文可用高度不足、三栏不可调整；Markdown不能导入；实体管理和已建立简历替换不完整。

本阶段目标是自然语言提出修改、核对变化、明确应用并保存，必要时恢复旧稿；同时改善等待、阅读、导入及持续管理体验。用户自行选择并提供资料，不要求AI IDE配合、仓库读取或自动同步。资料准备成本与改写质量仍观察，不宣称已解决。

## 价值与验收方向

以同一份资料完成提出修改、流式查看、多轮调整、应用保存、恢复旧稿和重开使用。观察手动复制次数、误覆盖、等待可感知性及任务结果，不把流式、界面美化或功能完成直接等同成本收益成立。

人物隔离、资料选择、背景明确确认、版本冲突保护和调用结果不明不自动重调继续沿用P1。具体功能见[产品设计](02_产品设计.md)。
