# S03 导入与显式引用交付验证

## 实现范围

POI XWPF5.5.1、PDFBox3.0.8固定版本，Java17编译。服务端解析txt/docx/文本层PDF，确认前允许修正，确认与原件分开保存；V4保存确认快照、材料用途、工作区显式辅助引用。辅助材料不能建立/替换当前简历。引用、撤销不改简历、不触发分析。材料删除前展示引用工作区，确认后撤销，恢复不会复活引用。

原件256KiB、文本256KiB、PDF40页、DOCX解压8MiB/256条目，解析单并发/等待5秒。超时线程不保证强制终止，但继续占解析槽直到真实结束，不叠加无限线程。不提供OCR、布局还原、恶意文件沙箱。文件原件待服务端提取阶段正文只读，避免前端把二进制预览提示保存成正文；提取成功后修正再确认。

材料用途当前创建时明确选择，旧材料默认简历来源。已确认正文仍不可原地覆盖：本轮可新增材料重新检查并撤销旧引用，不提供材料逻辑根下的更新/比较合并界面。确认快照不是完整材料版本管理。当前没有AI建议或摘要，未伪造依赖失效实现。
