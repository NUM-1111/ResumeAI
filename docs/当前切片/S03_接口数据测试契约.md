# S03 文档导入和辅助引用契约

本切片不调用模型。原件256KiB、提取文本256KiB；docx解压总量8MiB/最多256条目，PDF最多40页；解析单并发、等待最多5秒，超时返回明确失败，运行中的解析未结束前拒绝新解析，不假装已终止线程。此为受限本机合成资料机制，不是恶意文件隔离沙箱。

沿用POST material-imports，text/base64二选一；base64支持UTF-8 txt、docx、文本层pdf，由服务端解析，不接受前端伪造提取结果。失败无材料元数据；加密、无文本、损坏、不支持、超限分别说明。提取仅正文/表格文本，不承诺顺序/布局完整、图像内容或OCR；预览统一显示可能遗漏提示，修正并确认后才可用。

V4增加materialKind（RESUME/REFERENCE，默认RESUME）、每次确认的不可变文本快照表、工作区材料引用表。引用独立于当前稿来源，只有REFERENCE可作为辅助引用，只有RESUME可初始化/替换；旧记录保持RESUME。已确认正文不原地更新，修改为新材料并重新确认；更新/比较合并仍待后续，不能以旧确认放行新正文。

GET `/profiles/{p}/workspaces/{w}/material-references`返回当前显式引用及有效确认文本；POST同路径 body={materialId,expectedVersion}，DELETE同路径/{m} body={expectedVersion}。mutations均CSRF+幂等+档案事务锁。归属/确认/生命周期检查必需，过期409；重复引用明确返回当前状态，不重复创建。引用不改当前稿或个人事实，不触发分析。当前无建议/摘要对象，不伪造失效测试。

材料删除预览显示全部引用工作区；确认后原子撤销该材料所有引用，包括回收中区，材料恢复不复活引用。工作区删除保留其关系但不可访问；档案删除保留同批次关系，恢复后仅有效材料引用可用；此前已删除材料不复活。预览摘要包括引用状态，引用变化409重新预览。

前端：材料区按类型标记，添加时选择简历/辅助，辅助可检查/确认/明确引用/撤销；当前引用独立列表，中央预览、右侧操作，切区重载引用。确认、引用与建稿是不同授权。
