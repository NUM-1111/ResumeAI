# S02 安全删除与回收站交付验证

## 范围与实际实现

承接用户“S01基本交互没有大问题”的反馈收口S01已实现范围。S02增加档案/工作区/材料删除预览、确认、回收站和恢复。V3只增加软删除列、批次表和索引，不改V1/V2，不物理删除原件或修订，无自动过期/清空接口。规则及接口见[S02契约](S02_安全回收契约.md)。

工作区回收不回收共享材料。档案恢复仅还原同一批次，之前独立回收项仍在回收站。材料当前来源绑定阻止删除，包括回收中的工作区（先恢复并更换稿件）；历史出处保留但不阻止回收。恢复父档案后才可恢复独立回收子项。正常列表/读取/保存/来源选择排除回收对象。

## 失败与限制

首轮旧环境测试和smoke仍硬编码迁移2，实际3导致失败；同步到3复测。新增测试材料名称重复触发原有重复保护，改用唯一合成名后通过。失败不删日志。

未做永久清理、材料原件物理移动、引用/AI建议生命周期（尚未实现）、备份恢复；不把数据库回收站当备份。当前文件仅逻辑不可用，保留受控目录原件。未复演全新空库V1—V3、进程崩溃故障注入或多进程压力。父批次影响预览以数量列出子对象，不是完整无限列表。回收站按ID游标分页，不承诺按删除时间排序。用户页面验收待反馈。旧8080用户进程未停止，需要stop/run加载新包；旧包不具备回收过滤，升级后不要并行运行旧包写库。
