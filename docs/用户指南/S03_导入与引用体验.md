# S03 只体验新增导入与引用

在WSL启动已有17数据库和新版应用（正在运行旧版时先保存，再stop/run）：

```bash
python3 /root/java/ResumeAI/scripts/local.py db-start
python3 /root/java/ResumeAI/scripts/local.py stop
python3 /root/java/ResumeAI/scripts/local.py run
```

打开 http://127.0.0.1:8080/ ，沿用operator和原密码。使用合成文档，不需要F12或ID。

1. 进入已有工作区，左侧“＋ 添加简历材料”，上传docx或含文本层PDF（256KiB内、PDF40页内）。先点击右侧“保存为待检查材料”，再在中间检查提取文本并修正。提取不还原排版，图片不会识别。
2. 点击“确认检查后的文本”。没有当前稿时可“作为当前简历”；已有当前稿时只有明确“改用这份简历”并确认才替换。打开材料本身不改稿。
3. 左侧“＋ 添加辅助材料”，粘贴项目说明或上传文档，保存、检查确认，再点“明确引用到本区”。左侧“本区辅助引用”应出现它；“撤销本区引用”应移除，不改当前稿。

可选：删除已引用辅助材料，预览会说明撤销哪些引用；恢复材料后仍不自动引用。暂不需要反复造数据。

不支持.doc、扫描件/OCR、加密PDF。损坏、无文本或超限会提示改用文本/缩小文件。已确认正文不能原地覆盖，修改需新增材料重新确认；材料更新比较界面尚未做。

只反馈“上传后提取是否看得懂”“确认/引用入口是否清楚”“哪里与预期不同”。不是要求你审查每一项技术机制；遇到阻塞即可停下。
