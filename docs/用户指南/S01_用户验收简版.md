# S01 用户验收（整改完成后使用）

此文是整改后的页面体验入口。助手技术回归结果见当前切片整改记录；用户验收仍待你的实际反馈，不自动算通过。无需开F12、抓请求或填UUID，原先已反馈的问题也不用重记。

## 只走一次，不反复造数据

使用合成文本；复用你已创建的一个档案和工作区即可，不要求清理旧数据，也不要求记录ID。忘记密码才需要set-password，日常不反复更换密码。

左侧逐层进入“个人档案 → 工作区 → 工作区内容”，每层可搜索、加载更多和返回。新建通过“＋”弹窗填写，取消不创建。进入工作区后，左侧选择当前简历或档案共享材料，中间显示正文，右侧放操作。工作区设置在右侧操作区。已有当前稿可直接从第6步体验。基本交互已获用户认可，后续只体验新增功能，不要求重复整套验收。

## 新增：删除与恢复（S02）

使用合成数据：选择档案后右侧“删除个人档案”；进入工作区后右侧“删除工作区”；点开材料后右侧“删除材料”。先查看影响，取消不删除，确认后进入回收站。顶部“回收站”可恢复，不提供永久清空。

建议只体验一次“删除工作区 → 顶部回收站 → 恢复 → 重新进入”，确认当前稿和共享材料还在。材料若仍是当前简历来源，会阻止删除并列出工作区，先更换当前简历再删除。回收中的工作区仍保留来源关系，需要先恢复再更换。先单独删除工作区再删除档案时，恢复档案不会自动复活此前单独删除的区；先恢复档案，再单独恢复该区。

合成文本：

```text
演示候选人
项目：订单演示系统
职责：参与接口设计。
说明：仅用于测试，不是真实经历。
```

| 步骤 | 做什么 | 应看到什么 | 不符合时怎么反馈 |
| --- | --- | --- | --- |
| 1 登录 | 用operator及自己的密码进入 | 中文提示，成功到工作台；输错仍在登录页且错误可理解 | 例如“输错后跳到空白页”即可 |
| 2 选位置 | 选已有档案和一个未建立当前稿的工作区；没有才创建 | 清楚显示当前人物、工作区、方向和下一步 | 例如“找不到创建入口” |
| 3 添加材料 | 左侧“＋ 添加简历材料”，在中间填名称和正文，右侧“保存为待检查材料” | 显示待检查，并明确尚未进入当前简历 | 例如“保存后不知道去哪” |
| 4 检查确认 | 把“参与接口设计”改为“负责接口设计，协助部署”，然后确认 | 材料显示已确认；不是自动认证经历真实 | 反馈改后文字是否仍在 |
| 5 开始编辑 | 右侧“作为当前简历” | 主编辑区出现修正后的文字 | 反馈是否必须猜测按钮 |
| 6 保存重开 | 末尾加“技术栈：Java。”，等已保存，再刷新并选回工作区 | 增加的文字仍在 | 若丢失立即反馈，不需要查数据库 |
| 7 离开保护 | 新建导入粘贴一行尚未保存的文本，再尝试退出；在提示中取消 | 保留文本且没有退出 | 反馈是否能取消、文本是否保留 |

材料确认前修改名称会随确认一起保存；已确认后改名，点击右侧“保存材料名称”。这不修改正文或当前简历。

如需改用另一份简历：左侧选择另一份已确认材料 → 右侧“改用这份简历” → 对比弹窗中的替换前后内容 → 取消或明确“确认替换”。打开材料本身不会替换。旧稿保留在技术历史中，但历史恢复界面尚未实现。自动保存继续保留，技术修订号不作为用户版本展示。

只需回复：**走到第几步、看到什么、期望什么**。不强制表格和截图，不记录口令。遇到阻塞就停，由助手定位。冲突、网络故障、归属、接口响应、数据库约束由助手自动测试，不要求用户制造故障。

页面难用也是验收失败，不因接口测试通过降级成“仅样式建议”。
