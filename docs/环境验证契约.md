# ENV-02 最小工程验证契约

本轮仅验证运行基础，不实现 R01—R11 业务，不将下述表用作档案/简历表。

- 工程 `/root/java/ResumeAI`；验证实例 `/var/lib/postgresql/resumeai-validation`，以 postgres 系统用户运行，只绑定 127.0.0.1:55432，socket 也位于其专用目录。
- 数据库/非超级登录角色均为 agentcv_validation，使用随机本地口令及 SCRAM；不修改原 12/main，不安装组件。
- V1 创建 environment_checkpoint：id 主键且只能为 1，marker 非空中文文本，created_at 为带时区时间。插入一行确定性合成标记；Flyway 历史验证迁移身份。无用户资料。
- GET /api/v1/csrf：匿名可取 token/headerName/parameterName，no-store；登录退出后重取。
- GET /api/v1/environment：已认证会话可取 application/database/migrationVersion/marker/scope；真实查询失败不返回 CONNECTED；匿名 401。不返回路径、凭据、堆栈。
- /login 为本阶段 Spring Security 默认表单，单操作者 operator；服务端内存只持 BCrypt 散列，明文启动凭据保留于权限 600 的本地忽略配置；无注册和 JWT。
- CSRF 保持启用；POST /logout 必须带 token。业务登录接口和限流等完整契约留 S01，不宣称安全验收全部完成。
- Vue/TypeScript 使用最小渲染函数，无需为本验证额外引入组件插件；dist 经 Maven 资源打入 Boot JAR 的 static，部署仅使用 8080 回环入口，不启动 Vite 服务。
- 测试：V1 空库迁移、重复 migrate 不新增、中文查询、未登录 API 拒绝、登录会话、登录/退出 CSRF、真实 JAR HTTP 页面和资产获取；浏览器视觉交互另记未测，不以 HTTP 获取冒充浏览器渲染。
- 只允许合成数据；不调用任何模型或搜索 API。
