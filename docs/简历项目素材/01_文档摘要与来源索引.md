## 状态差异处理

- 索引及体验指南保留了历史状态，不能仅凭“待体验”否定后续用户确认，也不能凭确认推进就补记所有技术实验通过。
- D04 规划 CLAIMED/令牌；C03 现行单实例实现无该层，简历只描述实际原子领取、文件锁与状态条件保护。
- S06 早期强制 JSON Output；S09/C03 已移除 response_format，保留提示词结构协议与后端候选校验。
- D02/D04 早期无取消入口；S06 经用户授权增加“停止本地等待”，不保证供应商取消。
- 资料作为 system 文本组装并通过提示约束，不据此声称已验证抵御所有提示注入。
