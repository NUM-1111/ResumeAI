## 可复制正文

**项目一：AgentCV — AI简历工作台**  
独立开发（AI辅助编码）｜Vue 3 · TypeScript · Java 17 · Spring Boot · PostgreSQL · DeepSeek API

**简介：** 用户上传简历和项目材料，与AI讨论职责表述并手动修改简历；可保存确认过的经历供后续对话使用，并维护面向不同岗位的独立稿件。本人制定开发计划，组织AI工具实现并验收功能与交互。

- **简历导入与多稿管理：** 使用POI、PDFBox解析DOCX和文本型PDF，提供预览修正、自动保存及原件下载；同一份材料可供多份简历参考，简历复制后独立编辑，兼顾资料复用与稿件隔离。
- **经历提炼与确认保存：** AI从材料和对话中整理经历，用户可选择部分保存、纠正或撤回，后续对话复用已确认内容；针对“说明文字夹带JSON导致确认不生效”的实际问题，实现完整JSON对象提取与候选校验，展示确切条目后再确认入库。
- **异步对话与失败处理：** Spring Boot后台执行模型调用，Vue轮询获取结果，刷新后查询原请求而不重新生成；以PostgreSQL记录调用与保存状态，回答保存失败仅重试落库，调用超时不自动重调，并提供停止等待入口。
- **编辑与聊天输入保护：** 支持简历自动保存、聊天草稿恢复及生成期间编辑下一条消息；针对异步检查误读新输入的问题，固定点击发送时的文本，仅清除对应已发送内容，并以版本校验拒绝多页过期覆盖。

## 面试底稿与表述边界

- 产品初衷来自[需求分析§2—4](../阶段/P1_MVP/阶段设计/01_需求分析.md)的材料分散、背景重复解释、扩写核查和多稿混淆；[产品设计§4](../阶段/P1_MVP/阶段设计/02_产品设计.md)记录上传、独立复制、参考选择、对话及确认链路。收益未做受控对照，不写省时省钱百分比。
- 第1条不是RAG或OCR：当前是允许范围内全文组装，PDF只支持文本层。原件与数据库补偿详见[06工程底稿](06_通用Java版项目模块.md)及[03 H05](03_难点候选与工程闭环.md)。
- 第2条不是事实自动核验或任意语义确认：用户确认不代表外部真实性认证，后台采用有限语法/显式操作；普通模型建议不直接改简历。混合协议修复有测试记录，不承诺所有输出均能解析。
- 第3条单实例、单执行线程；停止只结束本地等待，不保证供应商取消或不收费。保存重试依赖当前进程暂存回答，重启可能丢失；不存在自动降级或多供应商切换。
- 第4条有浏览器回归与POST正文断言，不代表全部跨页竞态已经穷尽。已保存草稿可恢复，失败未保存部分不能保证重开找回。
- 完整六环节工程链继续保留在[03](03_难点候选与工程闭环.md)和[06](06_通用Java版项目模块.md)。HTTP正文总期限、诊断、迟到拒写作为第3条的追问素材，不再独占难以理解的简历标题。
