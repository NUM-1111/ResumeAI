## 使用规则

- 来源编号 D01—D05、S01—S09、C01—C08 在 01 中定义；难点 H01—H08 在 03 中定义。相同编号在整个文档组内含义一致。
- **事实·设计**只能证明设计决定；**事实·实现**证明文档记录或代码存在；**事实·验证记录**证明历史记录称已验证。本次未重跑业务测试，不能称本轮重新实测通过。
- **推断**用于岗位匹配及抽象能力，不升级为实际实现或效果；**待补证据**不能转成确定成果或量化收益。
- 最新修订覆盖同一机制的早期实现描述，历史失败保留。用户体验认可、替身测试、真实数据库/HTTP、浏览器 fixture、真实模型调用分别计证。
- 个人贡献尚未逐项归属。项目模块正文采用项目层面的成果描述；投递前必须核实本人参与范围，不能直接加“独立完成”“主导全栈”等措辞。
- 当前项目口径：**面向个人自用与演示的单实例 AI 简历工作台，MVP 核心链路已实现，最终验收收口中**。不宣称完整 MVP 验收通过。
- 不复制个人经历正文、账户余额、密钥、供应商请求标识、数据库身份或会话数据。来源链接指向原文用于内部复核，外发时只复制项目模块正文。
