## 可复制正文

**项目一：AgentCV — AI简历工作台**

**技术栈：** Java 17、Spring Boot 3.5、Spring JDBC、PostgreSQL 17、DeepSeek API、Vue 3、TypeScript

**项目简介：** 面向多目标简历维护，整合材料管理、独立稿件编辑与AI对话，支持背景提炼、确认保存及跨工作区复用。

- **背景记忆可信写入：** 针对模型推断可能混入长期背景的问题，设计“候选—确认—有效背景”分离机制，将写入绑定用户确认的正文与版本，仅保存明确确认项；将确认保存与模型生成解耦，失败重试无需重新调用模型。
- **异步回答依据一致性：** 针对资料更新后在途回答与当前资料不一致的问题，受理时固定输入快照并记录依据版本；资料变更后标记旧回答，后续请求携带最新资料及变更说明，避免将旧回答误认为基于最新信息生成。
- **外部调用分阶段恢复：** 针对网络异常、进程重启与落库失败可能诱发重复调用的问题，设计持久请求状态机，结合幂等受理与短事务，分离模型执行和结果保存；保存失败仅重试落库，可能已外发但结果不明的请求不自动重调。
- **完整响应超时与迟到防护：** 针对模型请求偶发长时间等待，定位响应头返回后正文读取脱离超时保护的缺陷，为完整响应设置总期限；停止本地等待后，通过请求状态校验拒绝迟到结果写入，不将本地中断视为供应商已取消。
