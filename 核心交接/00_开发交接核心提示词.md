### 2. 已确认的技术与环境方向

- 新项目独立存放，WSL Linux作为唯一主开发环境和主工作树。禁止Windows/WSL两份应用树双向编辑；旧原型只读，不清理、重置或覆盖其未提交改动。
- Java 17 + Spring Boot 3.5；PostgreSQL + Spring JDBC（JdbcClient/JdbcTemplate）+ Flyway；Spring Security单操作者口令、服务端会话、CSRF，不做注册平台或JWT架构。
- Vue 3 + TypeScript + Vite；前端构建产物由Boot同源托管，开发代理不当作正式部署入口。
- 原始文件放本地受控目录，数据库存元数据、确认文本和业务记录；POI XWPF处理docx，PDFBox处理文本层PDF。
- 优先LangChain4j接入。方案A：MiMo `mimo-v2.6-flash`主选，DeepSeek `deepseek-flash`手动备选；不自动路由或静默失败切换。DeepSeek Search独立接入，用户显式请求才限定搜索，必要时另评估Fetch。
- 模型ID、价格、数据条款和协议属于时效信息，接入时核验；示例版本不是项目锁定版本。实际兼容失败若需改变技术方向，说明证据并交用户决定，不静默换栈。
- 不默认加入Redis、消息队列、向量数据库、多Agent或微服务。后台有界执行加状态轮询；重启遗留任务标中断，不自动重放计费调用或写回。

### 3. 不可破坏的业务边界

- 一个档案对应一个人；背景跨该人的工作区复用，不同人材料、建议、文件与任务不能串用。单操作者认证不能替代逐对象归属检查。
- 一个工作区维护一份独立当前简历，方向是属性，同方向可多区。三种起点：复制同档案已有区当前稿、选择已检查确认的档案简历材料、导入新稿。复制不覆盖来源；来源JD、分析、任务摘要、未采用建议不自动带入。
- 首轮必须支持中文纯文本、`.docx`、含文本层PDF导入；不做`.doc`、扫描件/OCR，不承诺排版还原。提取文本可检查修正，确认后才可用；辅助材料须明确引用，未引用内容不进分析。
- 单JD、多JD综合、无JD方向参考均支持，本次目标明确选择。导入、切JD或改背景不自动分析；目标变化后旧建议保留查看但暂停采用。
- 自然语言请求改写不等于授权写回；模型建议与正式简历分开。页面采用或明确自然语言授权须校验对象、范围、版本、目标及依据；拒绝不改稿，歧义先问。
- 分析前自动保存，失败不分析服务端旧稿；同次多项采用原子完成；部分采用后剩余旧建议暂停。成功内容保存保留修订，历史恢复生成新稿，不回滚事实或激活旧建议。
- 清楚自然语言事实陈述可确认并展示同步结果；假设、含糊或冲突先追问。润色、采用、导入检查、整份替换、保存、删除简历都不自动确认/撤回事实。纠正/撤回背景不自动改已保存稿。
- 材料更新/撤销引用/移除使已知依赖建议暂停，历史摘要标明变化；不承诺发现全部语义关联。历史出处与当前材料绑定分开，复制继承有效绑定，可显式转独立文本稿解除，不自动撤销辅助引用或事实。
- R11是可持久回看的简短AI任务摘要，包含目标、主要判断、简要依据/未知及实际处理结果；不是完整聊天检索、隐藏思维链或全量技术日志。无改稿追问也记录，摘要失败不重做写回。
- 保存、写回、摘要、导出状态分别真实呈现；失败给文本兜底。未保存内容导出取页面快照，不静默输出旧稿，不把下载当保存；不承诺关页后恢复未保存内容。
- 删除先展示影响并确认，回收站首轮不自动永久清理；删工作区不删档案共享材料。备份恢复须有实际实现和隔离演练，不只是说明，可用维护命令承载。
- 默认回环访问且单操作者口令；局域显式开启并加密，不开放公网。密钥不进前端/仓库/日志，原文件不放公开静态目录。
- 首次外发/切换供应商明确接收方及范围；核验API条款后才发真实资料。搜索不带姓名、联系方式、完整简历、面试记录，不认证经历；展示网址和获取时间；网页是数据不是指令。
