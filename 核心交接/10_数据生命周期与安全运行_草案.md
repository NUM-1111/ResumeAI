# AgentCV 数据生命周期与安全运行（设计草案）

> 用户已接受第1节整组运行策略，备份恢复的实现与演练纳入首轮工程交付。具体组件、配置、命令和验证仍待详细设计，不表示已配置安全组件、已完成备份或已验证恢复。服务仅本人本机/局域使用，不开放公网。模型与搜索方案按ADR-001执行。

## 1. 已确认的运行策略

| 范围 | 已确认策略 | 取舍 |
| --- | --- | --- |
| 默认运行 | 仅绑定回环地址，Vue构建产物由Boot同源托管；PostgreSQL及材料目录不直接对浏览器暴露 | 减少演示部署单元，不表示本机模式可以忽略跨站请求和对象归属检查 |
| 局域访问 | 必须显式开启，配置访问口令与HTTPS或受保护隧道；防火墙限制来源，不做公网映射 | 增加配置成本，但不能在局域网明文发送口令和简历 |
| 访问身份 | 一个操作者身份，不新增用户注册体系；建议本机也使用同一访问口令和会话机制 | 保持运行模式一致，不将个人档案当成登录账号 |
| 回收站 | 首轮不自动永久清除；支持查看与恢复。需要释放空间时，由操作者在维护流程中明确确认清理范围并先做备份 | 降低误删风险，但磁盘占用会增长；不声称数据已物理擦除 |
| 备份 | 人工触发、临时停止业务写入，取得数据库与材料目录一致副本并记录备份清单；不引入自动远程备份 | 操作简单但需要短暂维护窗口；不提供零停机或自动容灾承诺 |
| 恢复 | 在隔离目录/实例中验证备份，显式确认后切换；不直接覆盖正在运行的数据 | 增加恢复步骤，避免用未验证副本破坏现有数据 |
| 外发 | 模型与搜索分开控制，说明供应商与发送范围；首次外发或更换供应商时明确授权 | 不必每个模型调用重复确认，但不能静默改换接收方或扩大资料范围 |

选择“不自动清理”后，回收站恢复不以一个未说明的短期限为前提；之后若加入自动过期策略，须单独告知并评审。维护清理不是本轮新增批量删除产品功能，其脚本/步骤、对象清单和确认机制在运行说明中补齐。

## 2. 数据归属与恢复边界

- 档案删除将所属工作区及材料按本次删除批次回收，不影响其他档案。
- 工作区删除只回收工作区所属稿件、历史、JD关联、分析、任务摘要和引用，不删除档案共享材料与事实。
- 恢复父对象只恢复同一次级联删除的对象，不复活此前独立删除的内容；恢复工作区要求其档案有效。
- 材料恢复需明确检查/恢复引用，不自动送入新分析。历史来源身份可以保留，但原件已清理时必须显示不可用。
- 当前稿来源材料仍被选作当前简历时先更换再移除；复制继承当前绑定，明确转为独立文本稿可解除，历史出处保留，按07/12已确认规则执行。
- 数据库软删除、文件回收、备份保留是不同状态；清理活动必须检查有效引用、当前稿来源及备份影响，不能按文件名直接删除。

## 3. 认证、会话与文件访问建议

- 已确认采用Spring Security管理单操作者口令认证和服务端会话；具体版本配置待验证，不自行实现密码加密算法。未登录可GET `/api/v1/csrf`获取token/headerName，登录或退出后重新获取；写入及上传带请求头token，响应不缓存。
- 口令只保存安全散列；API密钥由服务端环境或受控配置提供，不进入前端构建、仓库、数据库业务导出和日志。
- Cookie建议HttpOnly、SameSite约束；局域HTTPS启用Secure。对写操作启用CSRF保护，拒绝任意CORS来源；具体配置须通过实际浏览器验证。
- 登录失败限流、会话过期/退出、未登录API拒绝均须有明确行为；不把局域网当成可信认证凭据。
- 所有材料下载/预览经过应用归属检查；原件不得放在静态资源公开目录，不向浏览器返回服务器绝对路径。
- 开发用Vite服务不得作为可随意暴露的生产入口；开发代理和端口另在运行说明明确。

## 4. 外部模型与搜索的数据边界

- 首次发送前展示供应商、涉及当前简历/引用材料/档案背景的范围及外发提示。既有授权不涵盖未引用文件，也不涵盖自动向备选供应商发送。
- 程序在任务范围内最小化上下文，尽量排除无关联系方式等信息；不保证自动脱敏完全可靠。真实材料使用前核验API数据使用和保留条款，条款不清先用合成/脱敏材料。
- 用户触发搜索不等于同意将完整简历发送给搜索服务；查询只含必要公开岗位/公司关键词，不带用户个人材料，不自动搜索本人。
- 搜索网址、获取时间、来源类型与任务关联；网页内容不能提升模型权限。公开网页抓取须限制协议、目标、重定向和响应体，阻止本机/内网/云元数据地址等不安全目标。
- 本地删除不能撤销已经外发给供应商的数据，不承诺代替供应商清理。用户界面和说明必须明确这个限制。

## 5. 备份与恢复验收设计

| 场景 | 预期 |
| --- | --- |
| 备份时有运行任务或写请求 | 进入维护状态，停止接受新写入，处理已有任务后才取得一致副本；不能只复制正在变化的文件目录 |
| 备份完成 | 清单含备份时间、应用/数据库结构版本、数据库与文件集合校验信息；不含明文API密钥；备份失败不标成功 |
| 恢复演练 | 在独立环境检查当前稿、历史、材料、回收站、任务摘要及文件关联可用性，不调用真实模型、不自动搜索 |
| 恢复后存在运行中状态 | 标记为中断待处理，不重放写回或自动重启计费调用 |
| 确认恢复 | 明确副本时间及可能丢失的后续数据，保留恢复前副本；失败保留原环境，不误报恢复成功 |
| 备份存储 | 受控本地位置；若移到其他设备或云端须加密并另行授权，不自动上传 |

完整备份不等于同磁盘故障保护；只保存在同一磁盘不能称为灾难恢复。首轮恢复演练在可运行版本阶段执行，当前仅设计步骤和验收预期。

## 6. 日志、测试和后续收口

- 默认日志记录请求/任务身份、错误类别、耗时、实际结果等，不记录完整正文、提示词、密码或密钥。用户可读AI摘要独立管理，不混作诊断日志。
- 日志中含对象身份也需本机权限保护；导出诊断信息供面试展示前脱敏。
- 待验证：访问口令及HTTPS/隧道配置、备份清单格式和命令、会话策略、文件权限、上传解析资源限制、搜索地址安全检查。
- 测试应覆盖未登录访问、跨档案ID篡改、CSRF、路径穿越、查询隐私、回收站恢复和备份故障；列出测试计划不代表已通过。
- 第1节运行与生命周期策略已确认；组件具体配置、时间阈值、命令及接口由后续详细设计提出，不要求用户逐字段选择。备份恢复不只是一份说明，还须有可执行实现和恢复演练记录；可通过维护命令承载，不据此强制新增页面入口。
