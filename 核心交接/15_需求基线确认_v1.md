## 需求基线表

| 功能组（含编号） | 需求内容（一句话） | 决定 + 备注 |
| --- | --- | --- |
| 登录与访问保护（01） | 单操作者登录与访问保护。 | 保留 |
| 人物档案与隔离（02） | 个人档案创建、选择与人物隔离。 | 保留 |
| 工作区（03） | 多工作区手动创建，方向只是标签，不自动拆分合并。 | 保留；第一版不做方向模板、版本树、批量派生 |
| 起始简历来源（04） | 起始简历支持导入新稿及复制已有工作区当前稿。 | 保留；“从档案选已确认材料作为起始”延后，触发条件：需要从档案材料初始化起始稿时 |
| 导入与检查确认（05、06） | 中文简历与辅助材料导入后，提取文本须经检查、修正与确认门禁。 | 保留 |
| 重复导入（07） | 重复导入处理。 | 保留；文件名或内容哈希相同即提示，只提示不决定，不比较、不覆盖、不继承确认；文件只进人物档案，工作区只引用不上传 |
| 材料引用与撤销（08） | 辅助材料明确引用及撤销。 | 保留；单份勾选引用、查看、单份撤销；不做用途分类、不做批量引用 |
| 材料变化后的建议暂停与历史标记（09） | 材料变化后暂停相关建议并标记历史依据变化。 | 保留 |
| 来源绑定与独立化（10） | 当前来源绑定与独立化。 | 不保留；第一版不做来源绑定，复制/初始化生成全新独立稿，取消独立化，保留工作区分区 |
| 已有区导入新稿去向（11） | 已有区导入新稿的三种去向。 | 不保留；换稿走新建工作区，留材料走档案上传+引用 |
| JD 管理与目标切换（12） | JD 管理、分析范围与目标切换。 | 延后；接入模型/分析切片开始前再定 |
| 发起任务与追问（13） | 用户发起自然语言任务，系统按需分析与追问。 | 保留 |
| 建议对照（14） | 建议与当前稿分离并展示修改对照。 | 保留 |
| 授权写回（15） | 页面或自然语言授权后受控原子写回。 | 延后；接入模型/分析切片开始前再定 |
| 事实层（16、17） | 支持事实确认与背景同步，以及事实纠正、撤回和相关依赖处理。 | 延后；分析切片 |
| 分析门禁（18） | 分析当前稿前自动保存，保存失败不分析服务端旧稿。 | 延后；分析切片 |
| 保存（19、20） | 当前稿自动保存并可重开，保存失败或冲突时保护页面内容和离开操作。 | 保留；S01 核心；19 交接记载已实现、用户验收未通过、整改后待体验；20 已实现待体验，异常路径未全部验收 |
| 历史稿（21） | 查看历史稿并恢复为新当前稿，保留恢复前稿件且不回退事实或激活旧建议。 | 延后；历史切片 |
| 任务摘要（22、23） | 持久回看任务摘要，摘要失败与实际操作结果分离。 | 延后；分析切片之后，形态待真实使用后定，现在不做设计 |
| 导出（24、25） | 支持中文纯文本及未保存页面快照导出，失败不损坏工作稿或误报保存。 | 延后；导出切片 |
| 删除回收（26、27、28、29） | 档案、工作区及材料经影响确认后删除回收，并按对象归属与删除批次恢复。 | 延后；回收切片；档案回收所属数据，工作区删除不删共享材料与事实，材料移除处理引用影响；取消不变，首轮不自动永久清除，恢复不静默恢复材料引用 |
| 备份演练（30） | 一致备份数据库与材料并隔离恢复演练，失败保留原环境且不重放计费任务或写回。 | 延后；运维切片 |
| 模型接入与手动切换（31） | MiMo主选、DeepSeek手动备选，主模型失败明确提示，不自动切换供应商或同时发送资料。 | 延后；模型切片 |
| 资料外发授权与范围（32） | 首次外发、切换供应商或扩大范围时说明接收方及资料范围并取得授权，真实资料发送前核验条款，本地删除不撤销供应商已接收的数据。 | 延后；模型切片 |
| 分析上下文与材料读取（33） | 分析仅使用本次允许的简历、目标、已引用材料及相关背景，按需读取片段，容量不足说明遗漏范围，不将材料指令或历史摘要当作新增授权及事实。 | 延后；分析切片 |
| 模型任务运行与取消（34） | 任务后台执行并可查询、重连和取消，查询失败不等同模型失败，重启遗留任务标中断且不自动重放，取消不承诺撤销远端计费。 | 延后；模型切片 |
| 模型调用限额与失败退出（35） | 模型调用、耗时、输出及读取设有限上限，错误输出或超时只允许受限修复或重试，失败停止且不产生可采用的残缺建议。 | 延后；模型切片 |
| 限定联网搜索（36） | 用户明确请求后才搜索公开岗位或公司招聘信息，查询不带个人材料，结果标来源和时间，失败不伪造要求，网页不得扩大权限，全文抓取仅为候选能力。 | 延后；搜索切片 |
| 局域访问与敏感资料保护（37） | 默认本机访问，局域访问须显式开启并加密，不开放公网，密钥留在服务端，材料访问经过归属检查且原件不公开暴露。 | 延后；安全切片 |
| 诊断记录与敏感日志（38） | 保留必要任务身份、耗时、调用统计、错误及停止原因，缺失指标记未知，默认不记录完整简历、提示词或秘密，并与用户任务摘要分开。 | 延后；模型/安全切片 |
| 原始材料保存与可用性（39） | 保存原件并提供受控查看或下载，文件与元数据异常时明确不可用、不得误报成功，并处理孤立文件，不承诺已清理原件仍可打开。 | 保留；S01 导入功能的必要组成。原件保存、受控查看/下载、文件异常时明确不可用，S01 验收时一并验 |
| 工作台信息结构与定位联动（40） | 工作台采用左侧导航、中间当前稿及右侧任务与建议，支持建议定位原文（第一版仅验左侧导航+中间当前稿；右侧及定位联动延后到分析切片） | 保留；仅限“左侧导航+中间当前稿”部分，作为 S01 的 UI 验收依据；“右侧任务与建议”及建议定位联动延后到分析切片 |
